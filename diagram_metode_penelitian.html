Metode SDLC (Software Development Life Cycle) - Model Waterfall

  • Karakteristik: Pendekatan sekuensial dan terstruktur
  • Tahapan: Analisis → Perancangan → Implementasi → Pengujian → Evaluasi
  • Kelebihan: Sistematis, mudah dipahami, dokumentasi lengkap
  • Cocok untuk: Proyek dengan kebutuhan yang jelas dan stabil

4. Arsitektur Sistem AI Agent Chatbot

flowchart TB User[👤 Pelanggan] -->|Kirim Pesan| WA[📱 WhatsApp] WA -->|API Request| WAHA[🔌 WAHA
WhatsApp API Gateway] WAHA -->|Webhook| N8N[⚙️ n8n Workflow
Automation] N8N -->|Process Message| AI[🤖 Gemini AI
Natural Language Processing] AI -->|Understand Intent| N8N N8N -->|Query Data| DB[(📊 Google Sheets
Data Sparepart & Harga)] DB -->|Return Data| N8N N8N -->|Generate Response| AI AI -->|AI Response| N8N N8N -->|Send Reply| WAHA WAHA -->|API Response| WA WA -->|Terima Balasan| User style User fill:#4CAF50,stroke:#2E7D32,color:#fff style WA fill:#25D366,stroke:#128C7E,color:#fff style WAHA fill:#2196F3,stroke:#1565C0,color:#fff style N8N fill:#FF6D00,stroke:#E65100,color:#fff style AI fill:#9C27B0,stroke:#6A1B9A,color:#fff style DB fill:#FF9800,stroke:#F57C00,color:#fff

Komponen Sistem:

  • WhatsApp: Platform komunikasi dengan pelanggan
  • WAHA: Gateway untuk menghubungkan WhatsApp dengan sistem backend
  • n8n: Workflow automation untuk mengatur alur logika chatbot
  • Gemini AI: Model AI dengan kemampuan NLP bawaan untuk memahami dan merespons pesan
  • Google Sheets: Database untuk menyimpan data sparepart, harga, dan informasi toko
